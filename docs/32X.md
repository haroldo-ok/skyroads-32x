# Sega 32X port

The 32X target uses the original portable SkyRoads game/physics/rendering core,
the master SH-2 for game logic and the 32X packed-pixel VDP, and the 68000 for
controller/VBlank service plus native Genesis music. At build time, the
original OPL2 scores are converted to standard VGM 1.50 streams. The 68000
plays those streams through the console's real Yamaha YM2612 at the original
180.018 Hz event cadence. The slave SH-2 is dedicated to original PCM intro
and gameplay effects over stereo 32X PWM at 22,050 Hz.

Immutable game data is decoded at build time and read from cartridge ROM so
the 256 KiB SDRAM budget is respected. This includes all 14 converted VGM
tracks and all five SFX.SND samples; no runtime file I/O or heap allocation is
needed.
The ROM asset initializer also seeds the fixed car palette (entries 72-91) and
dashboard palette (entries 92-141) before loading each road/world palette.

## Controls

| 32X/Genesis pad | Action |
| --- | --- |
| D-pad | Menu/road selection; steer and accelerate/brake in game |
| A or C | Select / jump |
| B | Back / escape |
| Start | Select in menus / pause in game |

The port intentionally uses the reliable 3-button subset. Some 32X emulators
mirror d-pad state into the 6-button extended nibble during the 68000 pad
handshake. Reading X/Y/Z/Mode therefore made every direction look like a jump
or back command. `sr32_read_pad()` masks the input to U/D/L/R, A/B/C and Start.

## Genesis VGM music and 32X PWM effects

- **Conversion:** `tools/opl2_to_vgm.py` expands every MUZAX score into a
  standard, looping VGM 1.50 file with YM2612 (`0x52`/`0x53`) register writes
  and 44.1 kHz VGM waits. All 14 files are reproducible build artifacts.
- **Yamaha FM:** the six OPL2 melodic channels map to all six YM2612 channels.
  OPL attack/decay/sustain/release, multiplier, total-level, feedback, and
  FM/additive connection settings are translated to OPN2 parameters. The two
  unused operators are muted so each converted patch retains its original
  two-operator structure.
- **Rhythm:** OPL rhythm voices use short Genesis PSG tone/noise envelopes,
  preserving all six Yamaha FM channels for melody instead of stealing one
  for drums.
- **Timing/player:** a Work-RAM-resident 68000 VGM player is clocked by YM2612
  Timer A at approximately 180 Hz, matching SkyRoads' original PIT cadence.
  YM busy waits and VGM command batches are bounded, so faulty audio cannot
  stall controller/VBlank service or cause a black screen.
- **Effects:** INTRO.SND and all five SFX.SND samples retain their original
  Sound Blaster time constants and are resampled by the slave SH-2 into stereo
  22.05 kHz PWM. Because the source recordings have widely different levels,
  gameplay effects receive per-sample Q8 normalization to use about 94% of PWM
  range without clipping; INTRO.SND remains at unity gain.
- **Mix balance:** audible YM2612 carrier operators reserve about 6 dB of
  headroom, preventing native FM music from masking the normalized PWM effects.
  PWM values remain inside the safe hardware range 2-1032.
- **Settings:** the original Sound On/Off menu controls both YM2612/PSG music
  and PWM effects.

The 68000's initialized Work RAM image is deliberately placed before the large
VGM blob in cartridge ROM. This keeps boot-time copying in the fixed low ROM
window and avoids a black-screen failure seen when some 32X emulators had to
fetch that image from beyond the music data.

The stock skeleton also tried to release the slave through a stale `r0` after
running C initializers. Startup reloads COMM0 before clearing COMM4, ensuring
the PWM sound CPU leaves its `S_OK` handshake on hardware and emulators. Audio
commands remain non-blocking.

## Build

Install [Chilly Willy's Sega devkit / 32XDK 20220418](https://github.com/viciious/32XDK/releases/tag/20220418)
at `/opt/toolchains/sega`, or set `GENDEV` to its extracted `sega` directory.
Place the freeware SkyRoads data files in the repository root, then run:

```sh
make -f Makefile.32x -j release
# custom toolchain location:
make -f Makefile.32x -j GENDEV=/path/to/toolchains/sega release
```

Outputs:

- `release/SkyRoads32X.32x` — playable 32X cartridge ROM
- `release/SkyRoads32X-vgm.zip` — all 14 converted standard VGM tracks
- `release/SkyRoads32X-source.zip` — source/tools/tests (original data excluded)

The build runs `tests/verify_rom.py`, which verifies the Genesis and MARS
headers, checksum, SH-2 entry points, linked game-code markers, ELF sections,
and SDRAM/stack bounds. `tests/test_vgm_conversion.py` independently rebuilds
all tracks, validates both YM2612 ports, key-ons, waits, PSG rhythm, loop/end
commands, generated-file freshness, and the 68000 fixed-ROM size budget.

## Headless emulator tests

Build PicoDrive's libretro core:

```sh
git clone --depth 1 --recurse-submodules https://github.com/libretro/picodrive.git
make -C picodrive -f Makefile.libretro platform=unix -j
```

Run the point-to-point test:

```sh
python3 tests/run_emulator_tests.py \
  --core /path/to/picodrive/picodrive_libretro.so \
  --rom release/SkyRoads32X.32x
```

The test boots the real ROM and drives these checkpoints through PicoDrive:

1. intro is visible (anti-black-screen assertion),
2. intro -> main menu,
3. main menu -> road selection,
4. D-pad Down selects road 2 **without launching it**,
5. D-pad Up returns to road 1,
6. D-pad Right selects the second road column and Left returns,
7. Start launches road 1,
8. accelerate, jump with A, and continue gameplay,
9. ship and HUD crops contain their expected nonzero palette ranges,
10. intro PWM PCM, continuous native YM2612 VGM music, and the landing PWM
    effect produce measurable non-silent mixed Genesis audio.

Every checkpoint records a PPM screenshot, CRC32, color count, visible-pixel
ratio, and audio statistics (sample count, nonzero ratio, peak and mean
amplitude). The d-pad regression uses a pixel-difference bound: the road
highlight must move while the road-selection screen itself remains active.
The audio regression separately checks intro PWM PCM and YM2612 music after the
intro sample has ended. It then continues after the scripted landing, requires
at least 4,000 counts of peak headroom over music, and correlates mixed emulator
audio against the actual resampled landing waveform from SFX.SND. This prevents
a changing FM passage from producing a false-positive effects test. The static
PWM regression also verifies normalization and effective peak/RMS level for all
five effects.

## Current console-specific limitations

- Configuration/completion state lasts for the current power session; SRAM
  persistence is not yet implemented.
- X/Y/Z/Mode are ignored to avoid the emulator 6-button mirroring issue.
- YM2612 VGM and PWM audio are validated in PicoDrive; this revision has not
  yet been reported as tested on a physical 32X/Genesis.
